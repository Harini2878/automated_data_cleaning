
# Automated Data Cleaning & Schema Transformation

## Project Description
A Python-based automated data cleaning system using Pandas.

## Features
- Handles missing values
- Normalizes currency formats
- Standardizes date formats
- Removes duplicate records
- Validates dataset schema
- Generates validation reports

## Technologies Used
- Python 3
- Pandas

## How to Run

1. Install dependencies:

   pip install -r requirements.txt

2. Run the project:

   python main.py

## Output
- Cleaned dataset
- Automated validation report
